# 통합 강좌 데이터 사전

| 컬럼 | 설명 | 주의사항 |
|---|---|---|
| id | 전처리에서 생성한 레코드 ID | 재전처리 시 변경 가능 |
| center | 센터명 | 파일명 기준 |
| sport | 종목 | 원본 값, 표준화 미완료 |
| name | 강좌명 | 학습 수준이 포함될 수 있으나 일관되지는 않음 |
| time | 수업 시작~종료 시각 | 포맷 정제 추가 필요 |
| days | 요일 텍스트 | `(토)` 등의 비정규 표기 포함 |
| audience | 수강대상 | 결측 있음 |
| price | 원본 수강료 숫자 | 기준 기간·할인 여부 별도 검증 |
| capacity | 수강 정원 | 모집 잔여석 아님 |
| month | 수강월 | 과거 시점, 최신 신청 여부 아님 |
| course_id | 원본 강좌 식별번호 | 센터별 의미 상이 |
| period_start / period_end | 원본 기간 정보 | `9999-12-31`은 실시간 운영증거 아님 |
| score | API 응답만 포함 | 자료 완결성 지표, 추천 적합도 아님 |

출처: 한국체육산업개발(주) 공공데이터포털의 분당스포츠센터·올림픽스포츠센터 강좌정보 (사용자가 업로드한 CSV 파일).
