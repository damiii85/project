# 공모전 기획안 초안 — SPORT MATCH

## 문제 정의
운동을 시작하려는 이용자가 여러 공공체육시설의 강좌 가격·요일·시간·대상 조건을 일일이 비교해야 한다.

## 제안 가치
- 이용자: 강좌정보를 한눈에 비교하고 조건에 맞게 선택
- 기관: 공공데이터 재사용성을 높이며, 향후 익명화된 검색 수요를 통해 공급 부족 영역 발굴

## 대상
- 공공체육시설에서 수영·골프·요가 등 운동을 배우려는 일반 이용자
- 가족·근무시간·예산에 따라 운동 일정을 맞추려는 시민

## 현재 제공 범위
- 분당스포츠센터 / 올림픽스포츠센터 과거 강좌정보 활용
- 검색·필터·가격 비교 시연 가능
- 실시간 접수, 거리 기반 추천, 전국 시설 비교, 운영자 분석은 **미구현**

## 차별화 가설 (검증 필요)
현재 각 시설별 검색·신청 과정이 분리돼 있다면, 여러 센터를 비교해 사용자 상황에 맞춘 선택을 돕는 통합 UX에서 차별화 여지가 있다. 기존 서비스 현황과 사용자 인터뷰를 통해 검증한다.

## KPI 가설
- 같은 강좌 탐색 과제의 평균 완료 시간 감소
- 첫 페이지 상위 추천 후보에 대한 이용자 만족도
- 가격/시간 정보 정확도 및 데이터 최신성
- 강좌별 검색 수요 분포 (익명 집계)

## 제출 전 검증할 질문
- 기관 개방 데이터 1종 이상 활용요건 충족 및 제공기관 정확성
- 각 강좌 요금이 월 요금인지 기간 전체 요금인지
- 강좌 수준, 수강 대상, 접수 링크를 추가 수집할 수 있는지
- 타 기관 데이터 결합 시 표준화 가능성
- 심사 기준 및 제출물 형태·분량
