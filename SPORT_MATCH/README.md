# SPORT MATCH

**한국체육산업개발(주) 공공데이터 활용 경진대회** 출품 준비용 프로젝트입니다.

사용자의 운동 종목, 센터, 요일, 시간대, 예산을 기준으로 **과거 공개 강좌정보를 검색·비교**하는 실행 가능한 MVP입니다. 아직 실시간 예약·접수 서비스나 개인 맞춤 이동시간 분석, 수요 예측 모델은 구현되지 않았습니다.

## 바로 실행 (Python 3.10 이상, 외부 패키지 불필요)

프로젝트 최상위 폴더에서:

```bash
python scripts/prepare_data.py
python backend/server.py
```

Windows에서는 `python` 대신 `py -3.12` 등 설치된 Python 실행 명령을 사용할 수 있습니다.

브라우저에서 **http://localhost:8000** 접속. 종료는 터미널에서 `Ctrl+C`.

### 기능
- 종목·스포츠센터·검색어·요일·시간대·수강료 필터
- 2026년 기록 기본 표시, 역사 데이터 검색 옵션
- 가격·시간·정원·대상 비교 카드, 페이지 이동
- `/api/courses`, `/api/meta`, `/health` 로컬 JSON API
- 원본 CP949 CSV를 UTF-8 CSV/JSON으로 정규화
- 동일 강좌의 월별 반복 기록 중 최신 수강월만 선택
- 표준 라이브러리 기반 테스트

### 데이터 경고
- 원본: `data/raw/` (업로드된 두 CSV 원형 보존)
- 정규화 결과: `data/processed/`
- **데이터의 수강월은 현재 운영 여부를 보증하지 않습니다.** 현재 신청 가능 여부, 잔여 정원, 실시간 가격은 제공하지 않습니다.
- 두 센터에 동일한 운동 종목이 모두 존재하는 것은 아닙니다. 예를 들어 올림픽스포츠센터 CSV에는 `수영` 종목 기록이 없습니다.
- 결측 수강대상 및 비정상 날짜, `9999-12-31` 같은 종료일 의미는 신중하게 해석해야 합니다.
- 강좌별 최신 기록 선택 키는 `센터 + 강좌 식별번호 + 강좌명 + 시간 + 요일`입니다. 종목별로 수집 방식이 다르면 추가 개선이 필요합니다.
- 점수는 개인에게 맞는 정도가 아닌 데이터의 충실도·기록연도를 의미하며, UI에서는 점수를 노출하지 않습니다.
- 이 파일을 외부 공개할 경우, 원본 데이터의 이용허락조건과 출처표기 의무를 공공데이터포털에서 확인하세요.

## 프로젝트 폴더
```text
SPORT_MATCH/
├── backend/server.py          # HTTP 서버 및 필터 API
├── frontend/                  # 웹 인터페이스 (HTML/CSS/JS)
├── scripts/prepare_data.py    # 데이터 전처리
├── data/raw/                  # 사용자 제공 원본 CSV 두 개
├── data/processed/            # 전처리 결과
├── docs/                      # 기획·데이터 안내
├── tests/                     # 테스트
└── README.md
```

## 검증 명령
```bash
python -m unittest discover -s tests -v
```

## 향후 공모전 개발 로드맵
1. 추가 기관 강좌정보 수집 및 출처·데이터 최신성 검증
2. 종목/레벨/대상 표준화 + 매칭 조건 우선순위·설명 로직 도입
3. 좌표 및 이동시간 연계(별도 지도 API 필요)
4. 최신 모집·접수 링크 및 이용 가능 여부 연결
5. 기관 운영자용 수요 분석 대시보드(사용자 동의·집계 데이터 기반)
6. 정량 평가: 검색 소요시간, 추천 적합도, 데이터 커버리지
